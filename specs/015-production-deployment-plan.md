## 1. Approach

### 1.1 Four slices, ordered so each failure is unambiguous

1. **The image** (T1–T4). Measure it, rebuild it multi-stage as a non-root user
   on a movable port, then deal with the volume that change strands.
2. **The perimeter on the wire** (T5–T7). Headers, then the forwarded-header
   trust that makes one of them honest, then a real TLS terminator to prove it.
3. **Custody and spend** (T8–T11). File-backed secrets, a daily ceiling, a
   quieter `/health`, a posture that stops publishing Postgres.
4. **The record** (T12–T13). README, charter, mutation sweep, re-measure.

The order is not taste. Every T5–T11 change runs *inside* a container, so a
container that cannot start makes all of them ambiguous: a missing header and a
process that died at boot look identical through `curl`. Within slice 2 the
order reverses, because `Strict-Transport-Security` is conditional on HTTPS
(AC9) and nothing here produces an HTTPS request until T7 stands up Caddy — so
T5 and T6 ship with that branch exercised through a synthetic scope, and T7
turns it into evidence.

### 1.2 What does not move

Six of the thirteen tasks touch the request path, and a deployment iteration is
exactly where a safety property gets quietly traded away.

- **Nothing bypasses `execute_sql()`.** `/health` reads through it at
  `api/main.py:267` and continues to; charter §4's exemption count stays at
  **one**, and T10 reduces what `/health` reports, never how it asks. **The API
  holds only `querypilot_ro`** — `docker-compose.yml:53` is the one runtime DSN.
- **The ceiling refuses; it never sleeps.** `tests/test_ask_endpoint.py:143`
  AST-walks `api/main.py` for pacing imports; T9 returns a mapped failure with
  no backoff and no sleep.
- **`/health` stays credential-free**, one entry at `api/http/auth.py:95-102`,
  asserted at `tests/test_auth.py:305`; **unset credentials still fail closed**
  (`api/main.py:180-195`), and T8's `_FILE` reader fails the same way. **AC12
  survives**: the gate is middleware, `GET /nope` is a 401 and not a 404, and
  T5's headers middleware wraps it (D-1) rather than adding a 404 of its own.
- **Iteration 11's 923 hermetic tests stay hermetic** — T7's proxy tests need
  Docker and get a marker (D-5), not silence — and **absence assertions read
  code, not commentary**: four bugs of that shape are on the record, so every
  new "must not appear" test here parses YAML or the AST, or inspects the image.

## 2. The image slice

### 2.1 The builder stage attacks the only layer this project owns

§2 measures 133.8 MB of base image beneath a 92.2 MB dependency layer, and a
multi-stage build cannot touch the first number. The builder runs
`pip wheel -r requirements.lock -w /wheels`; the runtime stage runs
`pip install --no-cache-dir --no-index --find-links=/wheels`, so the pip and
wheel caches and any toolchain `psycopg` or `sqlglot` needs do not cross.
`api/Dockerfile:18-19` becomes two stages; `COPY . ./api/` at `:23` stays in the
runtime stage. `--no-index` is load-bearing: without it that stage reaches PyPI
and reinstalls silently while every test still passes.

### 2.2 UID 10001 strands a volume that already exists

`docker-compose.yml:88` sets `QUERYPILOT_HISTORY_PATH=/data/querypilot.db`,
`:95` mounts `querypilot_data` at `/data`, and `api/store/history.py:42-44`
resolves the same default — against a volume created by a root-running
container. After `USER 10001` the container starts, `/health` still reports
`database.connected: true`, and the only symptom is `history.writable: false`.
It fails on upgrade and not on a fresh start, so T4 is a task, not a line in T2.

### 2.3 `$PORT` is read once, and compose derives from the same value

`api/Dockerfile:25,27` hardcodes `8000` twice and `docker-compose.yml:127` a
third time. AC6 is satisfied by one shell-form entrypoint —
`exec uvicorn api.main:app --host 0.0.0.0 --port "${PORT:-8000}"` — where `exec`
is not cosmetic: without it `sh` stays PID 1, uvicorn never sees `SIGTERM`, and
every `docker compose down` takes the full kill timeout. The healthcheck then
interpolates `${API_PORT:-8000}`, the anti-drift discipline `pytest.ini:47-49`
already names for `DEFAULT_FLOOR`.

## 3. The perimeter on the wire

### 3.1 Ordering is decided by Starlette, and it reads backwards

`add_middleware` does `self.user_middleware.insert(0, …)` and
`build_middleware_stack` iterates `reversed(middleware)`, so **the last
`@app.middleware` decorator in the file is the outermost**.
`require_credentials` sits at `api/main.py:154-204`, so a headers middleware
defined *after* it wraps it and its headers reach the 401 built at
`api/main.py:147-151`; defined before it, the 401 short-circuits and carries
nothing. AC7's test walks `app.routes` with a route-count floor rather than a
hand-written list (`tests/test_auth.py:110-150`), including an unauthenticated
request so the 401 path is covered rather than assumed.

### 3.2 The CSP is derivable because the page has nothing inline

Measured, not assumed: `api/web/index.html:158` and `api/web/history.html:79`
each load a single external `/static/*.js`, and neither file contains an inline
`<script>` block, a `<style>` element, or a `style=` attribute. So
`default-src 'self'; frame-ancestors 'none'; base-uri 'none'` holds today with
no `unsafe-inline` anywhere, and AC8's job is to keep it true.

One nuance decides whether it stays true. CSP governs `style` **attributes** in
markup, including `element.setAttribute("style", …)`, and not CSSOM property
assignment; `api/web/app.js` sets SVG bar geometry, so a later change from
`el.style.width = …` to the attribute form would be blocked at runtime with a
green suite. AC8's test asserts the absence of the attribute form in both the
HTML and the JS, and strips comments first, because `api/web/app.js:10` and
`api/web/history.js:4` are comments *promising* not to use `innerHTML` — the
costume this repository's fourth recorded bug of the shape wore. It removes `//`
only at line start, since `api/web/app.js:408` holds
`"http://www.w3.org/2000/svg"`; a test proves it did not gut the file.

### 3.3 A forwarded header trusted unconditionally makes AC9 decorative

`X-Forwarded-Proto: https` from any client would let an attacker pin HSTS on the
host; the same header absent behind a real proxy turns it silently off. The
trust list is configuration (`QUERYPILOT_TRUSTED_PROXIES`, default empty,
meaning forwarded headers are ignored), and empty is the safe default because it
fails toward *no HSTS on plain HTTP* rather than *HSTS on a client's say-so*.
`uvicorn --proxy-headers` is rejected because it rewrites the ASGI scope before
the application sees it, putting the decision in a flag no test here can read.

## 4. Secrets and the ceiling

### 4.1 `_FILE` precedence, and the discipline that goes with it

`GROQ_API_KEY_FILE` and `QUERYPILOT_USERS_FILE` win over their plain forms when
both are present, because the deployment that sets the file form is the more
deliberate configuration; `docker-compose.yml:64,79` keep the plain form for the
laptop. The reader names the path in its errors, never the contents, and never
logs the value — the discipline `tests/test_auth_logic.py:116` and `:133`
already enforce for auth, the second at AST level rather than against a message.

### 4.2 The ceiling is a 503 that declines, not a 200 that answers

`api/http/errors.py:67` holds the precedent. `CATEGORY_RATE_LIMITED` is **503**,
and `api/http/errors.py:123-130` says why: the question was answerable and the
service could not try, so a negative answer would be a lie about the data. A
daily ceiling is the same shape, so it is 503 with `retryable=True`. Its message
is constrained by B-1 — it names an allowance and a reset and must not contain
"rejected", "blocked" or "denied", since "rejected" belongs to Gate 2 alone.
AC20 is met by adding the category to `RESPONSES` so
`tests/test_error_mapping.py:79` stays green **without being widened**.

## 6. Decisions

Six, and none is resolved here.

- **D-1 — middleware registration order.** Headers must appear on the 401, and
  Starlette's `insert(0, …)`/`reversed(…)` pair means the last decorator in the
  file is the outermost — so the headers middleware is defined **after**
  `require_credentials` ends at `api/main.py:204`, which reads backwards.
  *My lean: register it immediately after line 204, with the ordering rule in
  its docstring and a test asserting the 401 carries the headers.*

- **D-2 — where the daily counters live.** In-memory is trivial and resets on
  restart, which makes the ceiling defeatable by a crash loop and by any deploy;
  the SQLite store at `api/store/history.py` is volume-backed at `/data`.
  *My lean: reuse the store, and state the cost rather than wave at it.
  `AskRecord` (`api/store/history.py:90-118`) carries no identity, so this
  widens the dataclass and `api/store/schema.sql:6`, and the history database
  then holds who-asked-what — a step toward the per-user data charter §3 lists
  as a non-goal at `specs/000-project.md:207`. The narrower version is a counter
  table keyed by identity and UTC day, never joined to `ask`.*

- **D-3 — does the ceiling count questions or provider calls?** One question
  costs up to three calls under the agent loop, so a 50-question ceiling is a
  ceiling of up to 150 calls against a key measured at roughly 180 questions a
  day. Either unit is available: `AskRecord.provider_calls` records the real one.
  *My lean: count questions — the unit a user understands and the unit the
  refusal has to be written in. The tension belongs in the README: two loop-
  heavy identities at their limit can exhaust the key before the global ceiling
  of 150 is reached. Counting calls fixes that but is unpredictable.*

- **D-4 — where the `_FILE` reader lives.** There is no central config module;
  configuration is read per-module at point of use — `api/http/auth.py:68` for
  `QUERYPILOT_USERS`, the provider package for `GROQ_API_KEY`,
  `api/store/history.py:42` for the history path. A shared `api/config.py` is a
  new architectural seam; the alternative is two copies of a six-line reader.
  *My lean: one small `api/config.py` exporting `secret_from_env(name)`, because
  two copies of a security-relevant reader is how one later grows a fallback the
  other does not have. It is a new module, which deserves your agreement.*

- **D-5 — how the TLS and proxy tests are marked.** They need a Docker daemon
  and a running Caddy. They are not hermetic and not `needs_db` — they never
  touch Postgres, and `tests/isolation.py:224` would prohibit them if they did.
  *My lean: a third marker, `needs_proxy`, registered at `pytest.ini:50` beside
  `needs_db` and `constructs_engine`, which `--strict-markers` then makes
  mandatory. `tests/test_ci_guards.py:871`'s both-directions check is specific to
  `needs_db` and its census key, so it must widen to assert the new marker's set
  is disjoint from the hermetic lane — otherwise an unmarked proxy test joins the
  923 and that lane starts requiring Docker.*

- **D-6 — does T1's census belong in `tools/`, and does CI run it?** It needs a
  Docker daemon, and CI already boots the full stack at
  `.github/workflows/ci.yml:200` and dumps `docker compose logs` at `:285`.
  *My lean: `tools/` yes, matching `tools/measure_db_access.py`; CI no. The
  census is a measurement artifact, not an invariant, and a CI step regenerating
  it either fails the build on a megabyte of base-image drift or produces an
  artifact nobody reads. Those invariants are already tests in T2 and T5.*

## 7. Risks

- **The CSP is proved against today's page and broken by tomorrow's.** §3.2's
  test covers the attribute form and the inline block, not a future CDN font or
  third-party script, which would fail in the browser with a green suite.
- **T4's failure is invisible where people look.** A root-owned volume after
  `USER 10001` leaves `/health` reporting `status: ok` with
  `history.writable: false` — and after T10 that field is not visible without a
  credential at all. The README note is what closes the gap.
- **The trusted-proxy default is empty, which is safe and silently wrong behind
  a real proxy.** A deployment that forgets to set it gets no HSTS and logs the
  proxy's address as every client's. Neither failure announces itself.
- **A ceiling low enough to protect the key interrupts a demonstration.** 50 per
  identity against ~180 questions a day leaves room for three active identities
  and no more. The default is the user's to set, because the key is theirs.
- **T9's store choice is hard to reverse.** If D-2 lands on the history
  database, the schema ships and data accumulates; moving afterwards is a
  migration against the volume T4 already calls the fiddliest thing here.
- **The image may shrink disappointingly.** 133.8 MB of the measured total is
  base image and a multi-stage build cannot touch it. AC5 sets no target so a
  small number can be reported rather than chased into the rejected Alpine base.
